# 🌌 Cosmos

> **Explore. Build. Discover.**

**Cosmos** is an immersive space exploration and learning platform designed to make astronomy interactive, visual, and engaging.

Instead of simply reading about the universe, Cosmos lets users **explore it, interact with it, and learn by doing.**

### 🚀 Experience Cosmos

**[🌌 Launch the Live Demo](https://cosmos-115619459091.asia-southeast1.run.app)**

**[💻 View the Source Code](https://github.com/udayraj911/Cosmos)**

---

## ✨ What is Cosmos?

The universe is enormous, but learning about it doesn't have to be boring.

Cosmos combines **interactive experiences, 3D visualization, simulations, and educational content** into a single platform for exploring astronomy and space.

From discovering celestial objects to interacting with space-based simulations, Cosmos turns astronomy from something you simply **read about** into something you can **experience**.

---

## 🚀 Features

### 🌌 Universe Explorer

Explore the universe through an interactive visual experience and discover astronomical objects and concepts.

### 🪐 Interactive 3D Experiences

Interact with 3D space-related objects and environments to visualize astronomical concepts.

### 🚀 Space Simulations

Experiment with interactive simulations designed to make complex space concepts easier to understand.

### 🔭 Astronomy Learning

Discover planets, stars, galaxies, space-time, and other astronomical concepts through engaging educational experiences.

### 🧠 Learn by Exploration

Cosmos focuses on experiential learning instead of passive textbook-style content.

### 🎨 Immersive Interface

A modern, visually rich interface designed to create the feeling of actually exploring space.
